--- User Secrets backend ---


Percorso del file secrets.json su questa macchina: %APPDATA%\Microsoft\UserSecrets\aa9f6e84-1217-48e1-9783-b07f152f7874\secrets.json

Per leggere/modificare i valori (da eseguire dentro la cartella GestoraWebApi\):
  dotnet user-secrets list
  dotnet user-secrets set "JwtSettings:Secret" "nuovo-valore"
  dotnet user-secrets remove "JwtSettings:Secret"

Nota: questi valori vivono solo su questa macchina, fuori dal repo. Su un clone nuovo vanno
ricreati con "dotnet user-secrets init" + "set" (vedi CLAUDE.md sessione 13/08/2026 per i passaggi
completi).
